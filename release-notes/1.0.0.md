## InsumosGen 1.0.0

Primera versión instalable de InsumosGen. Ya no hace falta clonar el repositorio, instalar
Python a mano ni editar archivos: se descarga el instalador, se abre y la aplicación queda lista.

### Qué puedes hacer

- **Ofertas.** Genera e inserta ofertas preautorizadas en `botDB` y comprueba que quedaron
  guardadas correctamente, sin abrir el navegador. Puedes agregar varias ofertas en una misma
  corrida; se crean una tras otra.
- **Ventas CN y CF.** Ejecuta de punta a punta la venta de préstamo personal en el portal UAT,
  tanto para Cliente Nuevo (CN) como para Cliente Frecuente (CF). Puedes agregar varios lotes de
  venta en la misma corrida; se ejecutan de forma secuencial, uno después de otro.

### Instalación y actualizaciones

- **Setup.exe que prepara el entorno automáticamente.** Un instalador pequeño, que no pide
  permisos de administrador. Al instalar, prepara por su cuenta todo lo que la aplicación
  necesita: usa el Python que ya tengas si es la versión correcta y, si no, lo descarga e
  instala solo para tu usuario. Si algo se daña, el acceso *Reparar InsumosGen* del menú Inicio lo vuelve a armar.
- **Actualizaciones automáticas.** Al abrir la aplicación se comprueba si hay una versión
  nueva y, si la hay, se te avisa con las novedades y se instala con un clic. También puedes
  buscarla cuando quieras desde la pantalla de ajustes, donde se muestra la versión instalada.
  Si no hay conexión a internet, la aplicación sigue funcionando con normalidad.

### Conexión segura a las bases de datos

- **Sin archivo `.env`.** Los datos de conexión (servidor, usuario, contraseña y driver) se
  capturan desde la propia aplicación, en la pantalla *Conexiones*.
- **Contraseñas protegidas** con el Administrador de credenciales de Windows: se guardan cifradas
  para tu usuario y nunca quedan en archivos de texto.
- **Prueba de conexión** con un botón *Probar* que, si algo falla, te dice la causa real
  (servidor inalcanzable o sin VPN, driver ODBC faltante, usuario o contraseña incorrectos,
  sin permisos, tiempo de espera agotado). Antes de cada corrida se verifica también.
- Si ya tenías un `.env` de versiones anteriores, la aplicación importa tus conexiones una
  sola vez y te ofrece borrar el archivo.

### Pruebas de identidad con la cámara

- **Prueba de vida más estable y proceso más reactivo.** La verificación de identidad
  (Legalario) espera a que la cámara esté lista antes de grabar, falla menos y avanza sin
  esperas innecesarias.
- **Pickers para fotos.** Desde los ajustes eliges tu foto de frente, la INE (frente y
  reverso) y el comprobante de domicilio; la aplicación las guarda en tu carpeta de usuario.
- **Generador automático de fake video.** A partir de tu foto de frente, la aplicación genera
  sola el video que usa como cámara en la prueba de vida, sin comandos ni herramientas externas.
  Se vuelve a generar cuando cambias la foto.

### Primer arranque

Al abrir la aplicación por primera vez se te piden, una pantalla tras otra, las conexiones y
los ajustes que faltan (tus datos, las fotos y el video). No se puede operar hasta completarlos.

### Requisitos que debes instalar tú

Google Chrome y el *ODBC Driver for SQL Server* (17 o 18). Si falta alguno, la aplicación te lo
indica con el enlace de descarga oficial. Para consultar las bases de datos necesitas estar
conectado a la VPN del cliente.
