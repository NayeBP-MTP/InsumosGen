## Agency_Id Construction Rules

> **For NEW agencies created from now on, use the scheme in "New Agency_Id
> scheme" below, not the legacy random-suffix scheme.** The legacy scheme is
> kept here only to explain the `Agency_Id`s already in the table above. See
> `config/Context/NUEVA_ESTRUCTURA_AGENCIA.md` for the full rationale and
> `agents/agency-structure-creator.md` for how to generate one.

### New Agency_Id scheme (use this for new agencies)

```
[BBBB][YYMM][11][CCC]   (13 digits)
 ^^^^  ^^^^  ^^  ^^^
 |     |     |   └─ consecutivo 001-999, resets per (branch, YYMM)
 |     |     └───── fixed "11" — marks any insumo created by this tooling
 |     └─────────── creation year-month (YY + MM)
 └───────────────── branch number (same 4-digit branch numbers as below)
```

Example: Izcalli, Sep-2026, first agency of the month →
`2075` + `2609` + `11` + `001` = `2075260911001`.

**Never compute this by hand** — always call
`utils.agency_id_allocator.AgencyIdAllocator.get_unique_agency_id(branch)`
(see `agents/agency-structure-creator.md`), which reserves it in
`data/generated_agency_ids.sqlite3` so it can never collide with another one
generated by this tool or by `run.py`'s "Nueva estructura de agencia" flow.

### Legacy Agency_Id scheme (existing agencies only — do not use for new ones)

The 13-digit `Agency_Id` is constructed as follows:

1. **Branch Number** (4 digits): e.g., `2075`, `2093`, `2060`, `2049`, `2025`
2. **Padding Zeros** (3 digits): Always `000`
3. **Random Suffix** (3-4 digits): Random number, with zeros padding to reach 13 total digits

### Examples:
- `2075000001234` → Branch 2075 + 000 + suffix 001234 (6 digits)
- `2093000012345` → Branch 2093 + 000 + suffix 012345 (6 digits)
- `2060000000123` → Branch 2060 + 000 + suffix 000123 (6 digits)

### Pattern:
```
[BBBB][000][SSSSSS]
 ^^^^  ^^^  ^^^^^^
 |     |    └─ Random suffix (3-6 digits, padded with leading zeros)
 |     └────── Always "000"
 └──────────── Branch number (4 digits)
```

## Representative_Id Construction

Representative IDs follow a similar pattern but are typically shorter suffixes:

- Format: `[BBBB][000][SSSSS]` (13 digits)
- Example: `2075000012345` for a representative in Izcalli branch

## Maintained_By_Db_Id

This field contains **only the 4-digit branch number**:
- Izcalli: `2075`
- Tijuana: `2093`
- Zacatecas: `2060`
- San Luis Potosí: `2049`
- Aguascalientes: `2025`
